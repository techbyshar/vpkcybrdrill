# Vopak Terminal Cybersecurity Incident Exercise

Version: 2026.10.02-facilitator-record.1

## Run on a laptop

Unzip the package and open index.html in a current Chrome, Edge, or Firefox browser. No installation is required. The four videos and exercise run locally. External regulation links require internet access.

All actions are simulated. This tool makes no real agency notification, ServiceNow ticket, or terminal system change. Session entries stay in browser memory. Save the PDF before closing or refreshing.

## GitHub Pages

Upload the contents of this folder to your repository. In repository Settings, open Pages and select your publishing branch and root folder. Follow your organization's authorization and access requirements before choosing public hosting. The portable package itself supplies no login or access control.

## Replace the videos

Replace these files with improved MP4 clips using exactly the same names:

- assets/videos/inject-1.mp4
- assets/videos/inject-2.mp4
- assets/videos/inject-3.mp4
- assets/videos/inject-4.mp4

Use H.264 MP4 files with a horizontal 16:9 frame for broad playback support. Playback does not depend on clip length. Each clip has native Play controls and a Replay button. No autoplay or looping is used. Clips are muted.

The matching inject-1.jpg through inject-4.jpg files are preview posters. Replace these too if you want the poster to match the new clip. If an old asset remains visible, refresh the browser cache. Review each new clip against the written scenario before using it.

## Facilitation and assessment

Facilitator notes below relevant headings expand when clicked. They start collapsed. The existing response guidance still has its separate reveal control.

Assessment & points explains the method openly. Detailed criteria and evidence examples are in the facilitator assessment view until debrief. Each of 12 actions earns 2 points for independent demonstration, 1 after a prompt supplying missing direction, or 0 if not demonstrated or materially incorrect. N/A excludes the action with a reason. Repeating a question or asking why does not automatically reduce points.

Selecting an answer does not earn points. No speed points are awarded. Results distinguish independent performance, learning after discussion, and critical gaps. The percentage is an exercise assessment, not a compliance score.

## Print the report

At closeout, review the record and debrief. Select Print or save PDF and choose Save as PDF in your browser. The report includes the version, session elapsed time, stage elapsed time, video filenames, decisions, observations, evidence, learning, critical gaps, simulated contacts, corrective action, and participant signature lines. Print for signatures and retain through the approved facility records process.

The published site and this bundle use the same application source and version. Replacing media manually changes the local assets only and does not update the hosted site.

Each stage has one Facilitator record box for performance and prompting, learning after discussion, critical gaps, and any N/A reasons. Observation dropdowns remain per criterion. The combined record is included in the debrief and PDF.
